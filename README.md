# Pugazendhi R — Portfolio

Modern responsive portfolio with CSS reveal animations, typing text and project cards.

## Customize before publishing

1. In `index.html`, replace `YOUR_EMAIL@example.com` with your actual email address.
2. Replace `https://www.linkedin.com/` with your LinkedIn profile URL.
3. Add your resume PDF to this folder as `resume.pdf` (or remove the Resume button until ready).
4. Check all project descriptions and repository URLs.

## Publish using GitHub Pages

1. Sign in to GitHub as `pugazendhisolo-max`.
2. Create a **public** repository named `my-portfolio`.
3. Upload `index.html` (and optionally `resume.pdf`) to the repository root, then commit.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait for deployment, then visit `https://pugazendhisolo-max.github.io/my-portfolio/`.

No framework, build command, or hosting payment required.
